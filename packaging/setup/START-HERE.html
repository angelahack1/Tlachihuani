From download to ready

01 / EXTRACT

Extract the whole ZIP

Right-click the download and choose Extract All. Open the extracted folder before running setup. Keep the ZIP if you want to reinstall later.

02 / INSTALL

Choose your startup preference

Sign in as the Windows account that will operate XT. Open Installer.exe. Choose whether XT should appear at Windows sign-in. Select Review, check the version, account and destination, then Install. Approve Windows' administrator prompt.

03 / START XT

Find the gray XT icon

After Installation complete, XT opens in your normal Windows session. Check the tray's hidden-icons arrow. Both services stay stopped. The Desktop and Start shortcuts reopen XT whenever you need it.

04 / GO ONLINE

Choose Start Services

Right-click XT and choose Start Services. Its icon becomes colored when both services and the Torrenter API are ready. Open Panels → Torrenter Workspace inside Tlamatini.

Uninstall from Windows

For an orderly shutdown, choose Stop Services, then Exit tray.

Open Control Panel → Programs → Programs and Features, select Tlachihuani and choose Uninstall. Alternatively use Settings → Apps → Installed apps or Uninstall Tlachihuani in Start. Accept the Windows confirmation and administrator prompt.

Services, packaged files and setup-owned shortcuts/registry values are removed. Your downloaded files, exports, protected identities and job journal remain. Reinstall as the original Windows operator to reuse retained state. Follow any restart request from Windows.

The matching Uninstaller.exe in this ZIP is also available. It shows a review page before removal.

Help before you need it

I already have 0.1.0 or 0.2.0 installed

Stop Services, exit XT, uninstall the old version through Windows and install {{VERSION}} as the same operator. The preserved state is reused. This package does not perform an in-place upgrade. For a legacy script-managed installation, follow the migration guide; do not delete the old job journal.

The XT icon is missing

Open Tlachihuani XT from Start or the Desktop and inspect the hidden-icons arrow beside the clock. Those shortcuts also open the service overview. If you ran the entire installer as administrator, open XT yourself from your normal Desktop session. A gray XT means services are stopped or not yet ready.

The health address only displays JSON

The health check is a diagnostic endpoint. {"api_version":1,"engine":"ready"} is success. For your downloads, sign in to Tlamatini and use Panels → Torrenter Workspace.

Windows or my organization blocks setup

This build is unsigned. Follow your organization's software approval process; do not disable security controls. A signing certificate must be supplied by the publisher before a signed release can be produced. Ordinary XT operation uses the delegated operator permissions; installation and removal require administration.

Verify the download

SHA256SUMS.txt lists every package file's SHA-256 checksum. manifest.json records their sizes and version. A separate .zip.sha256 accompanies the ZIP. Checksums detect corruption; publisher signing is a separate release step.
